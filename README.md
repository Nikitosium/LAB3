# RS-31_Haponko_Nikita_RTOS_LR3

**Номер групи:** РС-31

**Автор:** Гапонько Нікіта

**ОПЕРАЦІЙНІ СИСТЕМИ РЕАЛЬНОГО ЧАСУ ТА 32-БІТНІ МК**
**Лабораторна робота 3.** Технологія розробки ПЗ ОСРЧ на основі патерну «Стан» та використання інтерфейсу USART.

**Обладнання:** STM32F411 Discovery, CubeMX, Keil.

**Мета:** Ознайомитися з принципами роботи інтерфейсу USART, навчитися реалізовувати обмін даними між пристроями та застосовувати патерн проєктування «Стан» (State Machine) для обробки подій.

__________________________________________________________________________________________

**Завдання до лабораторної роботи (Варіант 4):**
1. Організувати передачу рядка **«Test4»** через **USART1** (PA9 — TX) кожні 100 мс.
2. Прийняти дані через **USART3** та реалізувати відображення прийнятого рядка у вигляді **азбуки Морзе** на світлодіоді **PD15**.

Цей проєкт демонструє взаємодію між двома незалежними модулями USART всередині одного мікроконтролера та програмну дешифрацію символів у світлові сигнали.

### 👨🏼‍💻 Функціонал:
* **UART Transmitter**: Потік передачі, який циклічно відправляє ідентифікаційний рядок через USART1.
* **Mores Code Decoder**: Складна логіка, що перетворює ASCII-символи у послідовність "крапок" та "тире" (коротких та довгих спалахів).
* **State Machine**: Використання автомата станів для коректної обробки таймінгів світлодіода без блокування основної програми.

### 📋 Ключові моменти реалізації:
1. **Loopback Connection**: Для тестування TX (PA9) фізично з'єднується з RX іншого USART.
2. **Character Processing**: Кожен прийнятий символ ініціює запуск відповідної послідовності сигналів Морзе.
3. **Non-blocking Delays**: Реалізація патерну «Стан» дозволяє системі залишатися чутливою до нових вхідних даних під час відтворення поточного символу.
